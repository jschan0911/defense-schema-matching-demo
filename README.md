# Defense Schema Matching Demo

Case-study evaluation of SCHEMORA for mapping public, non-sensitive U.S.
Department of Defense contract-award metadata to the Open Contracting Data
Standard (OCDS), with a human-in-the-loop review interface.

This repository reports a bounded case study, not validation across the entire
defense domain.

## Status

The data, licensing, sensitivity, target design, and estimated run budget are
fixed in [`docs/execution_plan.md`](docs/execution_plan.md). No Matchmaker or
G.E.R. run is part of this repository.
